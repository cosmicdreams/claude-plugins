# Examination techniques

Four ways of questioning a corpus. Each finds a different kind of insight. In a seminar they are **beats**: a place for a student to start looking, never a list of allowed questions. A student may ask off-beat questions; the script tags them, it does not refuse them.

Read this file when writing student briefs by hand, when a student asks what its beat means, or when `synthesize` wants a technique to work through material without a seminar.

---

## 1. Pattern spotting

**Looks for:** themes several independent sources agree on.

**Shape of a good question:** one that forces sources to be compared, for example "Which recommendations for X hold across different team sizes, and which sources say so?"

**Record:** the pattern, the sources that support it, and how strong the agreement is.

## 2. Paradox hunting

**Looks for:** where conventional wisdom breaks down, sources contradict each other, or something seems true but is not.

**Shape of a good question:** "Source A says X works in setting S; does any source report X failing in S, and under what version or condition?"

**Record:** both positions, each with its source and its version or date qualifier, and what might explain the conflict. Do not merge the two positions into one claim; a conflict between sources is a finding.

## 3. Naming the unnamed

**Looks for:** behaviours, failure modes or strategies that sources describe repeatedly but never label.

**A good name is:** evocative (suggests its meaning), short (two or three words) and precise (does not overlap an existing term). Example: *stale success*, a metric improvement that hides broken behaviour.

**Record:** the name, a one-sentence definition, the sources that describe it, and why naming it helps. The seminar report lists these under **Vocabulary**.

## 4. Contrast creation

**Looks for:** the real trade-off between competing options.

**Shape of a good question:** "When would a team choose A over B, and what does each cost that the sources do not state up front?"

**Record:** a row per option: strengths, weaknesses, when to use, risk.

---

## Order

The techniques build on each other: patterns find the consensus, paradoxes test it, names make the exceptions discussable, and contrasts turn the findings into choices. When one reader works through material alone, run them in that order. In a seminar the students run in parallel, so order does not apply.

## Writing any question

- Self-contained: someone who has not read the brief can understand it.
- One uncertainty per question. Split bundled questions.
- Do not restate a seed question from the brief; ask what the brief does not already ask.
- Name the source, version or date range when the answer may differ across them.
